Site institucional desenvolvido para a **Pousada Lobo Guará**, localizada na região da Represa do Broa, em Itirapina/SP.

O projeto foi criado com foco em **presença digital, SEO local e conversão pelo WhatsApp**, apresentando acomodações, estrutura, localização e fotos reais da pousada.

🌐 **Projeto online:** https://pousadaloboguarabroa.com.br

## ✨ Funcionalidades

- Layout responsivo para celular e computador
- Galeria de fotos com lightbox
- Informações sobre as 7 suítes
- Destaque para piscina, estacionamento, área gourmet e Wi‑Fi
- Integração direta com WhatsApp para consulta de disponibilidade
- Google Maps incorporado
- SEO local com title, description, canonical e Open Graph
- Dados estruturados Schema.org para hospedagem
- Sitemap e robots.txt

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Maps Embed
- Schema.org / JSON-LD
- SEO técnico básico
- cPanel
- Git & GitHub

## 🎯 Objetivo

O objetivo do projeto é facilitar que hóspedes encontrem informações essenciais da pousada, visualizem a estrutura e iniciem rapidamente um atendimento pelo WhatsApp.

O site também foi preparado para melhorar a presença da pousada em pesquisas relacionadas a **hospedagem no Broa e em Itirapina/SP**.
